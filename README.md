# 🚗 Cars
## **Overview**
*Cars* is a **computer-animated** film produced by *Pixar Animation Studios* and released by *Walt Disney Pictures*.  
It follows the story of a race car named **Lightning McQueen** who learns that **life is about the journey, not just the finish line**.
> “Float like a Cadillac, sting like a Beemer!”
